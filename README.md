## 它解决什么问题

读外文长文时，整段翻译容易丢失对应关系：读完一段，分不清哪句译文对应哪句原文，查完一个词又要重新找回位置。

分句阅读把文章按句切分，原文与译文逐句对照排列，阅读、查词、朗读、笔记都在同一句话上完成，思路不被打断。

## 主要功能

### 逐句对照阅读

- 中英文按句自动切分（英文识别缩写与句末标点，中文按「。！？；」等标点断句），也可手动调整分句。
- 逐句显示译文，支持整篇批量翻译，也可只翻当前句。
- 提供 Bing、Google、百度、腾讯、DeepL、彩云、GPT 等多个翻译引擎，可随时切换与对比。
- 阅读进度、句数、词数自动统计，长文随时续读。

### 点词查词与生词本

- 阅读中直接点单词查看释义，支持导入本地 mdict 词典（可自定义 js/css 样式）。
- 生词自动进生词本，配合句子收藏、笔记、拼写练习一起复习。

### 朗读跟读

- 逐句朗读、整篇连读、自动跟读，朗读进度与阅读位置同步。
- 支持系统 TTS 及百度、Google、Bing 等在线语音，可调语速与音色。

### 多格式、多来源

txt、PDF、EPUB、Markdown、HTML、网页链接、RSS 订阅、视频字幕，以及拍照 / 相册图片取字，都能导入成一篇可分句的文章。

### AI 能力

- 内置 Gemini、OpenAI（ChatGPT）兼容接口，可用 AI 做逐句翻译、句子解析与长文追问。
- 支持本地 MCP 服务（仅监听 127.0.0.1），把查词、翻译、文章库、生词本等能力开放给 AI 客户端调用。

### 桌面端与移动端特色

- **Windows**：小窗模式边读边做别的事；`Ctrl + Enter` 快速翻译；全局热键 `Alt + S` 划词翻译、`Alt + Q` 截图取词；支持右键用本应用打开 PDF / EPUB；单实例运行。
- **Android**：屏幕翻译悬浮窗、无障碍取词、OCR 截图翻译、通知栏磁贴，以及从其他应用「分享」直接打开。

## 使用流程

1. 打开应用，粘贴文本，或导入 PDF / EPUB / 网页 / 图片。
2. 选择翻译引擎与目标语言，整篇分句并翻译。
3. 逐句阅读，点词查词、点句朗读，遇到好句子随手收藏。
4. 生词与笔记自动沉淀，随时回到生词本复习。
